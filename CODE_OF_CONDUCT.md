# Código de conducta

## Nuestra promesa

Como desarrollador y mantenedor de este proyecto, el objetivo es proporcionar un entorno abierto, didáctico y respetuoso para cualquiera que quiera aprender, usar o contribuir.

Se espera que todas las personas que interactúen en este repositorio (issues, pull requests, discusiones) lo hagan de forma respetuosa y profesional.

## Comportamiento esperado

- Ser respetuoso y educado en todo momento.
- Aceptar críticas constructivas y dar feedback de forma calmada.
- Enfocarse en el código y las ideas, no en las personas.
- Evitar lenguaje ofensivo, discriminatorio o despectivo.

## Comportamiento inaceptable

- Insultos, amenazas o ataques personales.
- Lenguaje que discrimine por razón de género, orientación sexual, origen, religión o cualquier otra condición personal.
- Compartir información privada de terceros sin su consentimiento.

## Alcance

Este código de conducta aplica a todas las áreas del repositorio: issues, discusiones, pull requests y cualquier otro canal asociado a este proyecto.

## Contacto

Si observas un comportamiento contrario a estas reglas, puedes contactar directamente por correo en:

- `valentindegennaro@gmail.com`

Se revisarán los casos y se podrán tomar medidas como bloquear a usuarios o cerrar discusiones que no respeten estas normas.
