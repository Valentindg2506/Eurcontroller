# Política de seguridad

Este proyecto se utiliza principalmente a nivel personal y educativo, pero se anima a reportar cualquier posible vulnerabilidad de seguridad.

## Versiones soportadas

Actualmente solo se considera soportada la rama `main` del repositorio.

## Cómo reportar vulnerabilidades

Si detectas un posible problema de seguridad (por ejemplo, inyección SQL, XSS, exposición de credenciales, etc.):

1. **No abras un issue público con detalles técnicos.**  
2. Envía un correo a: `valentindegennaro@gmail.com` con:
   - Descripción del problema.
   - Pasos para reproducirlo.
   - Impacto potencial.

Se intentará revisar y corregir el problema lo antes posible. Si procede, se publicará una nota en el changelog o en el README indicando que la vulnerabilidad ha sido corregida.
